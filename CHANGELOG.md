# Changelog

## 1.0.0 — Initial Android release

- Native Arabic RTL Android interface for live magnetometer readings.
- Local four-second baseline calibration, median/EMA filtering, noise-aware threshold and alert hysteresis.
- Live field gauge, 20-second signal plot, X/Y/Z readings, optional sound/haptics and CSV export.
- Added an up-front sensor limitations notice and M-Eleven developer/contact credits.
- MIT License.

**Build note:** the attached CI APK is a debug-signed test build for sideloading. It is not a production/Play Store-signed release.
