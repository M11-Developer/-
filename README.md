# مِرْصاد — كاشف المجال المغناطيسي لنظام Android

تطبيق Android أصلي باللغة العربية يقرأ **المجال المغناطيسي الفعلي** من حساس الهاتف، يعاير خط أساس للمكان، ثم يعرض الانحراف عنه أثناء المسح. لا توجد قراءات محاكاة أو حسابات سحابية أو إعلانات أو صلاحيات موقع.

> **حدّ فيزيائي مهم:** الهاتف لا يحتوي ملف إرسال/استقبال لكاشف معادن احترافي. هذا التطبيق يستخدم مقياس المجال الذي صُمّم أساسًا للبوصلة؛ لذلك قد يكشف تغيّرات قرب الحديد والصلب وبعض المغناطيسات، لكنه لا يستطيع كشف الذهب أو النحاس أو الألمنيوم مباشرةً، ولا يحدد نوع الجسم أو عمقه. وجود حسّاس أو غطاء مغناطيسي أو شاحن قد ينتج إشارة مشابهة. لا تعتمد عليه في الحفر أو السلامة الكهربائية.

## ما الذي يفعله التطبيق؟

- يقرأ `TYPE_MAGNETIC_FIELD` الحقيقي بوحدة µT، ويدعم احتياطًا `TYPE_MAGNETIC_FIELD_UNCALIBRATED` مع طرح انحياز الحساس الذي يبلّغ عنه Android.
- يعرض مقدار المجال الكلي، المحاور X/Y/Z، دقة الحساس ومداه الاسمي، والانحراف عن مرجع المكان.
- يستخدم وسيطًا متحركًا من خمس عينات ثم مرشح EMA منخفض التأخير لتقليل اهتزاز القراءة.
- يجمع مرجعًا محليًا لمدة أربع ثوانٍ، ويقدّر أرضية الضجيج بوسيط الانحراف المطلق MAD. عتبة التنبيه هي الأكبر بين الحساسية التي يحددها المستخدم وأربعة أمثال الضجيج/حد الدقة.
- يضيف تأكيدًا لثلاث عينات وعتبة تحرير بهسترة لتقليل التنبيهات المتقطعة.
- يعرض مسارًا حيًا لعشرين ثانية، ويقدم صوتًا واهتزازًا اختياريين، وتصدير CSV اختياريًا عبر منتقي ملفات Android.
- يعمل دون اتصال. لا يطلب الإنترنت أو الموقع أو الكاميرا؛ ولا يحفظ سجل الجلسة إلا إذا طلب المستخدم تصديره.

## البناء

المتطلبات: JDK 17، وAndroid SDK Platform 35، وBuild Tools 35.0.0 (مع Android Gradle Plugin 8.9.0 وGradle 8.11.1). افتح المشروع في Android Studio أو شغّل:

```bash
./gradlew testDebugUnitTest assembleDebug
```

ينتج APK التطوير في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

إذا لم يكن SDK مثبتًا، ثبّت Platform 35 وBuild Tools 35.0.0 من Android Studio > SDK Manager. يشغّل GitHub Actions الاختبارات والبناء على كل push وpull request. وبعد نجاح الاختبارات، يؤدي دفع وسم إصدار بصيغة `v*` إلى إنشاء GitHub prerelease وإرفاق APK تطوير موقّع بمفتاح debug. هذا الملف مخصص للاختبار والتثبيت الجانبي، وليس إصدارًا إنتاجيًا موقّعًا للنشر في Google Play.

## المعايرة والاستخدام

1. أزل غطاء الهاتف المغناطيسي، وأبعد الهاتف عن الحديد والمغانط والشاحن ومكبر الصوت.
2. اتركه ثابتًا واضغط **معايرة خط الأساس**. هذه معايرة للبيئة المحيطة، وليست ضبطًا مصنعيا أو تصحيحًا بيضاويًا للحساس.
3. ابدأ المسح وحرّك الهاتف ببطء وبمسافة قريبة من السطح. أعد المعايرة عند الانتقال لمكان مختلف.
4. إذا أبلغ Android عن دقة بوصلة منخفضة، حرّك الهاتف في الهواء على شكل 8 لتحسين معايرة النظام، ثم أعد معايرة خط الأساس داخل التطبيق.
5. ارتفاع القراءة يعني تغيّرًا في المجال؛ لا يثبت وحده وجود معدن. اختبر الهاتف أولًا بقطعة حديد معروفة، ثم قارن مع جهاز مرجعي إن كانت النتيجة مهمة.

## بنية المشروع

- `core/SignalProcessor.java` — ترشيح الإشارة، المعايرة، العتبة، والهسترة؛ مستقل عن Android.
- `ui/FieldGaugeView.java` و`ui/SignalChartView.java` — واجهة الرسم الأصلية دون مكتبات رسوم خارجية.
- `MainActivity.java` — واجهة عربية RTL وإدارة الحساس والتنبيهات وتصدير CSV.
- `app/src/test` — اختبارات وحدات للمعايرة والثبات عند تدوير الهاتف والهسترة والضجيج والتشبع.
- `docs/RESEARCH.md` — مراجعة النماذج والحدود الهندسية التي وجّهت التنفيذ.
- `CREDITS.md` و`LICENSE` — بيانات M-Eleven وترخيص MIT.
- `CHANGELOG.md` — ملاحظات الإصدار.

التطبيق لا يدّعي تفوقًا عدديًا أو مدى كشف محددًا؛ الأداء يعتمد على قطعة الحساس الموجودة في الهاتف والبيئة. للحصول على كشف غير حديدي أو أعماق أكبر يلزم جهاز خارجي بملف حثّي/نبضي وبروتوكول موثق، وليس نموذجًا برمجيًا فقط.
